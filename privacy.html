このアプリは、利用者のいかなる情報も収集・送信・共有しません。

収集する情報

ありません。氏名、メールアドレス、電話番号、位置情報、連絡先、写真、端末の識別子など、 個人を特定できる情報を一切取得しません。年齢や性別も尋ねません。

通信

このアプリはゲームの動作に通信を使いません。アプリ内から外部のサーバーへデータを送ることはなく、 広告、アクセス解析、クラッシュレポート、SDK の類も一切組み込んでいません。 初回の読み込み後は、インターネットに接続していなくても遊べます。

端末に保存されるもの

次のものだけを、お使いの端末の中（ブラウザのローカルストレージ）に保存します。 これらが端末の外へ出ることはありません。

  • 最高スコア（モードごと）
  • 集めた⭐（お題の達成数）の合計
  • 遊んだ回数
  • 選んだモード、音のオン・オフ、演出ひかえめの設定

これらは、ブラウザやアプリのデータを削除すると消えます。 アプリ内の「きろくを ほぞん・よみこみ」で作られる文字列も、 上記の内容をそのまま文字にしたものです。利用者ご自身がコピーして使うためのもので、 どこかへ送信されることはありません。

お子さまの利用について

このアプリは、お子さまが遊ぶことを想定して作られています。 上記のとおり個人情報を一切収集しないため、保護者の方の同意を必要とするデータの取り扱いはありません。 アプリ内に広告、課金、外部リンク、他の利用者とのやり取りの機能はありません。

第三者への提供

収集している情報がないため、第三者に提供する情報もありません。

このページの配信について

本アプリと本ページは GitHub Pages で公開しています。 ページの配信にあたり、GitHub 社のサーバーがアクセスログ（IPアドレス等）を 一時的に記録する場合があります。これは一般的なウェブサイトの閲覧と同じもので、 開発者はこのログを閲覧・利用しません。詳細は GitHub のプライバシーステートメント をご覧ください。

ポリシーの変更

内容を変更した場合は、このページに掲載し、上部の最終更新日を改めます。
