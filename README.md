# まめまる

**▶ 遊ぶ： https://tenfivetwo.github.io/chiisaku-naare/**

おなじ子どうしがくっつくと **ちいさくなる**、ふしぎな どうぶつパズル。
上のラインをこえないように、いちばん小さい子をなんびき見送れるかな？

- **通信を一切しません。** 外へ1バイトも出ません。記録も端末の中だけです
- **単一HTMLで完結。** ビルド工程はありません
- スマホ・PCブラウザ対応。PWA（ホーム画面に追加）対応

## スマホで遊ぶ

上のURLを開いて、**ホーム画面に追加**してください。全画面・オフラインで、
ふつうのアプリのように立ち上がります。

- iPhone … Safari で開く → 下の共有ボタン → 「ホーム画面に追加」
- Android … Chrome で開く → 右上の「︙」→ 「ホーム画面に追加」

※ ホーム画面から開いたぶんと、ブラウザで開いたぶんは**記録が別々**です。
移すときはタイトルの「記録を保存・読み込み」のコードを使ってください。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | **ゲーム本体。これ1つで動きます**（HTML・CSS・JSすべて内包） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面設定 |
| `sw.js` | オフライン用 Service Worker |
| `icons/` | アイコン各サイズ |
| `privacy.html` | プライバシーポリシー（ストア申請に必要） |
| `.nojekyll` | GitHub Pages の Jekyll 処理を無効化 |

公開に必要なのはこの6つだけです。`tools/` や `test-harness.js`、`_preview/`、
`store/` は確認用の道具と使い捨ての絵なので、公開には要りません。

## 更新するとき

**`index.html` を差し替えるだけです。**

`sw.js` の `VERSION` は上げなくてかまいません。`index.html` は
network-first（まずネット、だめならキャッシュ）なので、差し替えれば
オンラインの人にそのまま届きます。`VERSION` が効くのは**アイコンと manifest だけ**です。

以前は cache-first で、上げ忘れると遊ぶ人の端末で古い版が出つづけ、
リロードしても何日待っても直りませんでした。**cache-first に戻さないこと。**

## Android アプリ版

`index.html` をまるごとアプリの中に入れた WebView アプリがあります。
通信の許可を持たないので、機内モードでも動きます。
プロジェクトはこのリポジトリには置いていません（手元の `android/` フォルダ）。

**`index.html` を直したら、アプリ側のコピーも差し替えて APK を作りなおすこと。**
忘れるとブラウザ版とアプリ版で中身が食いちがいます。
