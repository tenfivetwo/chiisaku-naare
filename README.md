# ちいさくなあれ 〜ぎゅうぎゅうどうぶつえん〜

おなじ子どうしがくっつくと **ちいさくなる**、ふしぎな どうぶつパズル。
上のラインをこえないように、なんびきまで あつめられるかな？

- 通信を一切しない完全オフライン動作（単一HTML）
- スマホ・PCブラウザ対応、PWA（ホーム画面に追加）対応

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（これ1つで動きます） |
| `manifest.webmanifest` | アプリ名・アイコン・全画面設定 |
| `sw.js` | オフライン用 Service Worker |
| `icons/` | アイコン各サイズ |
| `.nojekyll` | GitHub Pages の Jekyll 処理を無効化 |

## 更新するとき

`index.html` を差し替えたら、**必ず `sw.js` の `VERSION` を上げてください。**

```js
const VERSION = "v1";   // ← v2, v3 ... と上げる
```

上げ忘れると、すでに遊んだ人の端末で古い版がキャッシュから表示され続けます。
